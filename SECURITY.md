# Security Policy

Please report security issues privately rather than opening a public issue.

- [CERT.LV coordinated disclosure programme](https://cvd.cert.lv/programs/view/101) (programme code SEQ)
- GitHub **Security Advisories**: "Report a vulnerability" on the repository's Security tab
- Email **security@offseq.com**

Include reproduction steps and the affected version. Repositories with their own `SECURITY.md` follow that file.
